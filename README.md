# Craft AI Studio

Bhau ye banana hai 

Build SHILPSETU AI, a modern mobile-first artisan commerce application.



PRODUCT:

Name: SHILPSETU AI

Tagline: “From Craft to Commerce in 60 Seconds”

Purpose: Help Indian artisans turn a simple product photo + regional-language voice description + basic costs into a professional, buyer-ready digital product listing.



IMPORTANT:

This is NOT a generic e-commerce marketplace.

Do NOT build a normal Amazon/Flipkart-style UI.

The product is an AI-powered creation assistant for artisans.



The experience should feel like:

Apple-quality mobile UX + modern Indian craft culture + bold editorial visual design.



The UI must be bold, expressive, artistic and modern while remaining extremely easy for a low-digital-literacy artisan to use.



==================================================

CORE UX PRINCIPLES

==================================================



1. One primary action per screen.

2. Large touch targets.

3. Very little typing.

4. Voice-first interaction.

5. Use icons + short labels.

6. High contrast.

7. Strong visual hierarchy.

8. AI actions must feel visible and understandable.

9. Never silently modify user input.

10. AI-generated information must always be editable.

11. Keep the artisan in control.

12. The interface should feel premium, not government-portal-like.

13. Avoid dense dashboards and unnecessary menus.

14. Avoid generic SaaS cards everywhere.

15. Use real product imagery and craft-inspired visual details.

16. Use subtle Indian craft patterns as decorative elements, never as distracting backgrounds.



==================================================

Primary colors:

- Deep Forest Green

- Warm Ivory / Sand

Typography:

- Short, confident labels

- High readability

Buttons:

- Large

- Bold

- Rounded but not overly bubbly

- Strong filled buttons

- Clear icon + text where appropriate

- Use prominent bottom CTAs

- Buttons should visually communicate hierarchy



Cards:

- Use cards selectively.

- Avoid endless small white cards.

- Use large visual blocks and strong section separation.

- Product imagery should dominate wherever relevant.



Visual style:

- Contemporary Indian design

- Premium craft marketplace aesthetic

- Editorial layouts

- Subtle paper/fabric texture

- Hand-drawn accent lines

- Minimal folk-inspired motifs

- Organic shapes

- Strong whitespace

- Bold photography



Do NOT make it look:

- childish

- overly corporate

- like a banking app

- like a generic AI dashboard

- like a template generated from shadcn defaults
